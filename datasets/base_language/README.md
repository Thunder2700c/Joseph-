# General language foundation corpus

## Selected source

The first general-language source is the Cosmopedia v2 configuration in the Hugging Face SmolLM-Corpus:

- Dataset: https://huggingface.co/datasets/HuggingFaceTB/smollm-corpus
- Configuration: cosmopedia-v2
- Pinned repository revision: 3ba9d60
- Dataset-card licence: Open Data Commons Attribution License (ODC-By) 1.0
- Content: synthetic educational text, textbooks, blog posts and stories generated by Mixtral-8x7B-Instruct-v0.1.
- Dataset-card snapshot: 39,134,000 rows; approximately 122 GB compressed download size for the full configuration.

The project uses only the generated text field. It deliberately excludes prompt and seed_data. It does not download or commit the full dataset. The acquisition script streams a capped, deduplicated sample to the ignored local artifacts directory and records the exact revision, selection settings and SHA-256 hashes in a manifest.

## Scope and limits

This is a general language pretraining source, not Hu Tao dialogue and not a source of her biography. It gives the model broad English written-language patterns. It does not by itself provide natural multi-turn chat, reliable instruction following, Hu Tao's voice or Teyvat knowledge. Those require separate original dialogue and character training after the former-life material is reviewed.

The default 200-million-character cap is a pilot-scale subset, not evidence that the final model has received enough training tokens. The manifest reports an approximate token count only; exact token counts are produced after fitting the tokenizer.
