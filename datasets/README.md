# Joseph datasets

Keep datasets small, documented, and traceable.

## Rules

- Record where each fact came from. Never mark a fact verified without at least one source.
- Keep manga, anime, supplementary material, and fan interpretation separate.
- Store claims in your own words. Do not commit manga scans, chapter text, anime video, or ripped subtitles.
- Include spoiler scope (Part number) when adding story facts.
- Use only training text that you have permission to use. Track license/terms for every bulk text corpus.
- A structured knowledge record is not automatically a language-model training sample.

The jojo folder currently contains only official series-catalogue metadata for Parts 1–9. It is not a complete JoJo knowledge base.
